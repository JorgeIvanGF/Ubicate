# Ubícate

Ubícate es un proyecto en preparación para ayudar a estudiantes universitarios de Tunja a encontrar alojamiento. La experiencia prevista permitirá explorar opciones en un mapa y consultar fotografías, precios, características, condiciones y disponibilidad.

El proyecto contempla inmuebles con una o varias unidades alquilables. A futuro, se considera ampliar el mercado a personas que buscan habitaciones y viviendas en general.

## Estado

F00-H03 y F00-H04 están cerrados con aprobación humana verificable. F01-H00 está abierto para evaluar arquitecturas, sin selección de stack o proveedor ni autorización de implementación. H00 y H01 cuentan con ratificaciones actuales, pero no se reconstruyen sus cierres históricos; H02 conserva orientación provisional. El estado global de Fase 0 es no cerrado por historial incompleto, no por una afirmación de que los hitos ausentes nunca se realizaron. La aplicación productiva, el framework y los servicios técnicos aún no se han definido ni implementado.
